# Experimental Results

Results placed here should be generated by the repository experiments and clearly labelled as **new experimental results**.

Do not mix these with numerical results reported in Shorten & Khoshgoftaar (2019).

Recommended reporting fields:

- Dataset and split
- Model architecture
- Augmentation policy
- Random seed
- Training configuration
- Validation metric
- Test metric
- Number of repetitions
- Mean and standard deviation
- Confidence interval where appropriate
- Notes on limitations

The purpose is to make the distinction between literature evidence and newly generated evidence explicit.
