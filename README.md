# Image Data Augmentation Tech Review

Interactive Streamlit demonstration for the **Computational Intelligence and Software Engineering** tech review on image data augmentation.

## Reference paper

Shorten, C. & Khoshgoftaar, T. M. (2019). *A survey on image data augmentation for deep learning*. Journal of Big Data, 6, 60.

## Demo

The application demonstrates practical image-space augmentation techniques:

- Geometric transformations
  - Horizontal / vertical flipping
  - Rotation
  - Translation
- Colour-space transformations
  - Brightness
  - Contrast
  - Colour saturation
  - Sharpness
- Kernel filters
  - Blur
  - Gaussian blur
  - Sharpen
  - Edge enhancement
- Random erasing
- Simple image mixing

The survey also covers broader approaches such as feature-space augmentation, adversarial training, GAN-based augmentation, neural style transfer and meta-learning. Those approaches require model/data pipelines beyond this lightweight interactive demo and are therefore not represented as implemented experiments here.

## Run locally

```bash
git clone https://github.com/Dinakarnayak/Image-Data-Augmentation-Tech-Review.git
cd Image-Data-Augmentation-Tech-Review
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

On Windows:

```powershell
.venv\Scripts\activate
streamlit run app.py
```
